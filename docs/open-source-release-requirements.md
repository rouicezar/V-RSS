# 开源发布验收要求

状态：已冻结（2026-08-08）

## 用户目标

新用户仅依赖 GitHub 仓库和 README，即可完成配置、启动、登录、选择采集方案、绑定该方案账号并同步公众号文章。

## 必须通过

1. Docker Compose 与本地 Node.js 两种部署路径均有可复制命令，首次启动会自动执行数据库迁移。
2. 方案1固定使用 `.xyz` 管线及方案1账号；方案2固定使用自有管线及方案2账号，不允许跨方案读取或改绑账号。
3. 当前方案被限流时允许用户手动切换；正在同步时禁止切换；限流状态和当前方案跨重启保留。
4. 后端、前端版本一致，前端不存在无意义的透明、空白或仅悬停可见交互区。
5. 生产部署不接受默认授权码；账号 token 加密落库且 API 不返回 token；外部抓取限制在预期微信域名。
6. README 准确说明前置条件、环境变量、两方案配置、首次使用、升级、备份、排错和已知边界。
7. 单元测试、构建、全新 SQLite 迁移、服务健康检查与 Docker 构建全部通过。
8. 提交前完成敏感信息、依赖漏洞、未跟踪产物和最终差异复审，然后提交并推送 `origin`。

## 非目标

- 不承诺绕过微信平台风控；系统只提供保守节流、熔断和人工管线切换。
- 本次仅正式支持 SQLite；不以修改一个环境变量即可使用 MySQL 的方式作不实承诺。
- AI 分析为可选能力，不作为公众号采集与 RSS 输出的启动条件。
