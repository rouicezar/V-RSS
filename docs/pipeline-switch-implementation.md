# 采集管线切换实现记录

## 已实现

- 数据库持久化全局当前方案，默认方案1。
- 账号记录所属方案，既有账号迁移为方案1。
- 登录、公众号信息、最新文章、历史文章统一按当前方案分发。
- 方案1使用 `Feed.id`，方案2使用 `Feed.fakerId`。
- 方案2缺少 `fakerId` 时明确报错，不再静默返回空列表。
- 运行中的更新全部或历史任务禁止切换。
- 公众号源页面增加方案1/方案2切换控件和当前状态。
- 方案1使用文章链接添加；方案2使用名称搜索添加。
- 账号页面显示账号所属方案。
- 修复方案1首次 429 未真正加入当日小黑屋的问题。
- 修复方案2登录失效时可能误标其他账号的问题。
- 修复历史账号迁移时两类 token 被统一归入方案1的问题。
- `.xyz` 返回通用 HTTP 401 时立即停用对应方案1账号，不再连续使用无效凭据。
